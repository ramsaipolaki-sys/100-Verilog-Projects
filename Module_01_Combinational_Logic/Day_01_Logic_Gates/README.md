# Day 01 – Logic Gates

## Objective

Design and verify basic logic gates using Verilog HDL.

## Logic Gates

- AND
- OR
- NOT
- NAND
- NOR
- XOR
- XNOR

## Tools Used

- Verilog HDL
- Xilinx Vivado

## Project Flow

Design → Testbench → Simulation → Verification

## Result

All seven basic logic gates were successfully designed and verified using simulation.
