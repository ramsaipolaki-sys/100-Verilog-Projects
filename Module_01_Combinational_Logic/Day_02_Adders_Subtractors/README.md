# Day 02 – Adders & Subtractors

## 🎯 Objective

Design and verify basic arithmetic circuits using Verilog HDL.

## Projects

1. Half Adder
2. Full Adder
3. Half Subtractor
4. Full Subtractor

## Tools Used

- Verilog HDL
- Xilinx Vivado

## Project Flow

Design → Testbench → Simulation → Verification

## Concepts Covered

- Binary Addition
- Binary Subtraction
- Sum
- Carry
- Difference
- Borrow
- XOR
- AND
- OR

## Result

All four arithmetic circuits will be designed and verified using Verilog simulation.
